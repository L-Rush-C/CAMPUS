# CAMPUS

Sistema de gestión para condominios y administradores, orientado a mejorar la organización de reservas, visitantes, vehículos, reportes, pagos y gestión de residentes.

## Objetivo

CAMPUS busca centralizar la administración del condominio en una plataforma que permita gestionar de manera ordenada las operaciones cotidianas, mejorar la comunicación entre residentes y administración, y facilitar el control de servicios y procesos internos.

## Funcionalidades principales

- Gestión de residentes
- Registro y control de visitantes
- Gestión de torres y espacios comunes
- Reservas de zonas comunes
- Gestión de vehículos
- Reportes y seguimiento de incidencias
- Control de pagos y cobros
